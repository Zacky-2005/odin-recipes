# Odin Recipes

This is a basic recipe website built with HTML as part of The Odin Project Foundations course.

The website will contain a homepage linking to three Kenyan recipes: beef pilau, chapati, and chicken stew.

## Skills Demonstrated

- Creating HTML boilerplate
- Using headings and paragraphs
- Emphasizing text with strong and emphasis elements
- Creating ordered and unordered lists
- Adding links between pages
- Displaying images with alternative text
- Organizing files and folders
- Using Git and GitHub to track and publish changes
